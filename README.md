## Projects
### [kanban-board](https://github.com/thetruesaftblandaren/kanban-board)
![Status](https://img.shields.io/badge/status-in%20progress-yellow)

A Kanban system that allows users to create boards and organize tasks (cards) into columns.

The system utilizes SignalR to provide real-time updates for users with access to a board, and JWT for authentication.
